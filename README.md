# Monari

Tools for my agency workflow, built on the **Monari** design system: neutral black-to-white, square, flat, full-bleed blocks. The work (client posts, photos, brands) carries the colour. The interface stays out of the way.

## Tools

| Tool | What it does | Status |
|---|---|---|
| [Grid Planner](grid-planner/) | Plan an Instagram grid, show it to the client exactly as it will look, collect pinned comments and get it approved in one link. | Frontend UI, mock data, no backend yet |
